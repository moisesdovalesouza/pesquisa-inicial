# Pesquisa Inicial

Publicações do Diário de Justiça Eletrônico Nacional (DJEN, do CNJ), processos e jurisprudência de todos os tribunais, no padrão visual do grupo Inicial.

Abra em **https://moisesdovalesouza.github.io/pesquisa-inicial/** no Chrome e instale como aplicativo.

Este repositório é um espelho: o programa é escrito no Termo Inicial (tela “Pesquisa processual”) e copiado para cá automaticamente. Não edite os arquivos aqui; eles são substituídos a cada atualização.

Nada é guardado fora do navegador de quem usa. O DJEN só responde a acessos feitos do Brasil.
